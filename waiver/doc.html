作業文件（Assignments）

  • HW1 Solve the following sudoku puzzle

    report code

    請用搜尋演算法解出數獨題目(題目在3_1. 搜尋演算法投影片的最後一頁)
    完成後須附上程式碼，以及相對應的說明文件(word或pdf)，說明文件需要包含程式執行結果截圖和程式碼說明
    Ex:
    執行最快的程式會額外加分
    若程式寫不出來可以"參考"別人的程式，但說明文件必須要自己寫並附上參考的對象，參考得到分數只會有基本分

  • HW2 Solve the square root of n by Genetic algorithm

    code

    輸入一個非負的整數n, 請用基因演算法計算根號n的值(square root of n)。

  • HW3 tic-tac-toe by alpha-beta or min-max algorithm

    report code

    使用老師上課所教的alpha-beta 演算法，來模擬tic-tac-toe遊戲的遊玩過程。程式需要有2個功能
    1. 人機對下，可以讓人與電腦遊玩，使用GUI或小黑窗顯示
    電腦或是玩家下的位置: 1 1
    當下盤面:
    _ _ _
    _ O _
    _ _ _
    2. 自我對戰，輸入要對戰的局數並顯示輸、贏、平手的局數
    ex: 輸入: 10
    輸出: 贏:1 輸:2 平手:7
    請大家繳交:
    1.程式碼
    2.相對應的說明文件(word or pdf)，文件當中請包含你的程式說明和輸出結果。

  • 期中報告

    paper slide

    請找一篇跟基因演算法、MCTS演算法、alpha-beta演算法等之前上課內容相關的論文，並進行報告。

  • 期末黑白棋競賽

    report code

    黑白棋棋盤大小: 6 x 6
    每個人的程式每一局最多下3分鐘(1手大約10秒)，超時就會算輸。
    請用min-max或是alpha-beta的方法寫出一個可以在平台上執行並順利完成比賽的程式碼。
    比賽結束後，請各位上傳程式碼，以及相對應的說明檔案(word 或是 pdf)，請描述你的程式是怎麼完成的、用了什麼方法。
    期末競賽成績計算: 比賽成績80% + 報告20%
    注意事項:
    1.不能用深度學習的方法。
    2.不能直接用網站上的Sample Code來比賽，如果比賽後發現沒有做任何修改直接用Sample Code來比賽，期末競賽分數只會有50分。
    3.未參加將視同期末未到。
